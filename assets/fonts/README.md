# IBM Plex Sans

Manyhands bundles six unmodified static IBM Plex Sans faces, sourced from
the npm package [`@ibm/plex-sans@1.1.0`](https://www.npmjs.com/package/@ibm/plex-sans/v/1.1.0),
under `fonts/complete/ttf`:

- `IBMPlexSans-Regular.ttf`
- `IBMPlexSans-Italic.ttf`
- `IBMPlexSans-Medium.ttf`
- `IBMPlexSans-SemiBold.ttf`
- `IBMPlexSans-Bold.ttf`
- `IBMPlexSans-BoldItalic.ttf`

The Linux desktop embeds these faces to provide consistent UI weights and
editor italics. They do not need to be installed as system fonts. macOS
and Windows use their native system UI fonts.
