## Task 20: Named controls in the details sheet

Commit 206177a holds the code and tests; this commit holds the ledger row.

- **What changed.**
  - While the tab is editing or saving, the details sheet's named fields
    are text fields: a document's Title, and a ticket's Title, Type,
    Status, Project and Team. They change the draft and mark the tab
    unsaved, as typing does. A field put back to its saved value leaves
    nothing to save.
  - While the private copy is being made ready, during the review and
    after Done keeps the draft, they stay read only.
  - A chip opens the sheet with its field's control focused.
  - Type, Status, Project and Team suggest the values on the tickets
    loaded for the repository. Any typed value is kept.
  - An emptied Project or Team is saved without the key.
  - An empty Title, Type or Status says why, for example "A ticket needs
    a type before it can be saved.", and every way to save waits.
  - `secondary-s` inside the sheet saves the tab, but not during the
    review.
  - Typing `closed` as the status saves text; the ticket stays open.
