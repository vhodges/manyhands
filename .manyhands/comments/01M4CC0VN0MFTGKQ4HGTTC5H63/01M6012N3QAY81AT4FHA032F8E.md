## Task 12: Local Images

Task 12 is in 1762192, with this record in the docs commit after it.

- **What changed.** Local raster images inside the repository show in
  the read view, in comment bodies and in the edit editor:
  - an image's `src` is parsed as a link target. An external `src`,
    another scheme and a refused path are never looked up, and show
    as their source;
  - a path resolves from the item's folder, in the item's own work
    context first, then on primary, else by the nearest file of that
    name in a walk of `docs/` that the tab keeps;
  - every file is read under the five containment checks, and is
    decoded off the UI thread, one at a time per tab, within fixed
    limits, a GIF's first frame only and a 256 MiB budget per tab;
  - the tab's editors share one cache, which the tab's reload clears.
- **Windows.** Stable `std` gives no file ID, so the identity check
  there compares size, creation and last-write times and attributes,
  and refuses a reparse point. This branch is not compiled locally.
- **Tests.** Each ran once at the end:

  - `images` 8;
  - `view::item` 98;
  - `discussion` 19;
  - `editor` 67;
  - the whole desktop binary: 719 passed, 0 failed.
- **Checks.** The desktop-only clippy, the all-targets all-features
  clippy and fmt are clean.
- No pre-existing or D3 test changed. No library gap, and no new
  dependency.
